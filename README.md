# Supmuseum

Here is our Supmuseum project. It is a web application that allows users to explore the museum's collection and learn more about the artworks. The project is built with React and Vite.
Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

## How to run the project

To run this project, do not forget to install the dependencies first:

```bash
npm install
```

Then, you can start the development server:

```bash
npm run dev
```
